# 素材授权模板（请同学签/回复）

先说明：**版权（Copyright）不会因为一句“给你”就自动转移**。你需要的是同学给你的**使用许可（License）**，
最好采用书面/聊天记录形式，明确：

- 作者是谁（同学的名字/网名）
- 授权哪些素材（模型文件、贴图文件名）
- 允许你做什么：使用、修改、打包、分发（包括附属和 DLC）
- 许可证：**GPL-3.0-or-later**（和项目一致）
- 是否要求署名（建议要求，写进 CREDITS）
- 授权期限/范围（建议：永久、全球、免费、不可撤销）

## 一、最简做法（微信/QQ 发这段，让对方明确回复“同意”）

> 我是《npc-tacz》模组的作者。你之前给我做的 `modern_soldier.json` 模型和
> `soldier/bandit/rebel/mercenary/bounty_hunter/modern_soldier.png` 贴图，我想正式放进模组和后续 DLC 里分发。
> 请你确认：你作为这些素材的作者，同意把它们以 **GPL-3.0-or-later** 许可证授权给《npc-tacz》及其附属/DLC
> 使用、修改、打包和分发，并允许在 CREDITS 中署名。授权是永久、全球、免费、不可撤销的。
> 你回复“同意”并写上日期即可，谢谢！

对方回复后：
1. 截图/保存聊天记录；
2. 把对方名字填进 `CREDITS.md`；
3. 把截图放到项目里（例如 `docs/asset-permission.png`）或自己留存。

## 二、正式一点（可复制成一份简单协议）

```
素材许可协议

许可方（作者）：__________（姓名/网名）
被许可方：npc-tacz 项目作者 __________

许可素材：
1. modern_soldier.json
2. soldier.png / bandit.png / rebel.png / mercenary.png / bounty_hunter.png / modern_soldier.png

许可内容：
许可方授予被许可方永久、全球、免费、不可撤销的许可，允许被许可方在
npc-tacz 及其附属模组、DLC 中复制、修改、打包、分发上述素材，
并以 GPL-3.0-or-later 许可证随项目分发。
被许可方应在 CREDITS 中保留许可方署名。

许可方签字/确认：__________   日期：__________
```

## 三、如果你真的想要“版权转让”

那需要单独的**著作权转让协议**（写明转让的权利种类、地域、期限、报酬等，双方签字），
一般个人模组没必要做到这一步；**独占/非独占许可**就足够合法使用和分发。
